# PostgreSQL Interview Questions and Answers

A growing set of interview questions to review while learning PostgreSQL. Try answering each question yourself before reading the answer, and add your own examples as you practice.

## Database and SQL fundamentals

### 1. What is PostgreSQL?

PostgreSQL is an open-source relational database management system (RDBMS). It stores data in tables and supports SQL, transactions, constraints, indexes, and features such as JSON data types.

### 2. What is the difference between SQL and PostgreSQL?

SQL is a language used to define, query, and manipulate relational data. PostgreSQL is a database system that implements SQL and provides additional features of its own.

### 3. What is a table, row, and column?

- A **table** organizes related data.
- A **row** is one record in a table.
- A **column** is an attribute shared by the table's records, such as `title` or `published_year`.

### 4. What is a primary key?

A primary key identifies each row in a table. Its values must be unique and cannot be `NULL`. A table has one primary-key constraint, which can consist of one or more columns.

### 5. What is a foreign key?

A foreign key links rows in one table to rows in another table by referencing a primary key or another unique key. It helps enforce referential integrity.

### 6. What is the difference between `PRIMARY KEY` and `UNIQUE`?

Both enforce uniqueness. A primary key also identifies a row and cannot contain `NULL`. A table can have one primary-key constraint and can have multiple unique constraints.

### 7. What is `NULL` in PostgreSQL?

`NULL` represents a missing or unknown value; it is not the same as zero or an empty string. Use `IS NULL` or `IS NOT NULL` to test for it, because comparisons such as `value = NULL` do not evaluate to true.

### 8. What is the difference between `WHERE` and `HAVING`?

`WHERE` filters rows before grouping. `HAVING` filters groups after `GROUP BY`, often using aggregate expressions.

```sql
SELECT author, COUNT(*) AS book_count
FROM books
WHERE published_year IS NOT NULL
GROUP BY author
HAVING COUNT(*) > 1;
```

### 9. What is a join?

A join combines related rows from two or more tables. Common types include:

- `INNER JOIN`: only rows with a match on both sides.
- `LEFT JOIN`: every row from the left side, with matching right-side data when available.
- `RIGHT JOIN`: every row from the right side, with matching left-side data when available.
- `FULL OUTER JOIN`: matching rows plus unmatched rows from both sides.

### 10. What is the difference between `DELETE`, `TRUNCATE`, and `DROP`?

- `DELETE` removes selected rows and can use a `WHERE` clause.
- `TRUNCATE` removes all rows from a table efficiently; it does not accept a `WHERE` clause.
- `DROP` removes the database object itself, such as a table.

Always check the target and understand transaction behavior before running data-removal statements.

## PostgreSQL concepts

### 11. What is an index?

An index is a data structure PostgreSQL can use to find rows more efficiently. Indexes can speed up some reads, but use storage and add work to inserts, updates, and deletes. Add indexes to support measured query patterns rather than indexing every column.

### 12. What is a transaction?

A transaction groups database operations into one unit. You can use `COMMIT` to make the changes permanent or `ROLLBACK` to undo uncommitted changes.

```sql
BEGIN;
UPDATE books SET published_year = 1937 WHERE title = 'The Hobbit';
COMMIT;
```

### 13. What does ACID mean?

- **Atomicity**: a transaction completes as a whole or is rolled back.
- **Consistency**: transactions preserve defined data rules.
- **Isolation**: concurrent transactions are isolated according to the selected isolation level.
- **Durability**: committed changes persist, subject to the database's durability configuration and infrastructure.

### 14. What is normalization?

Normalization organizes data to reduce unnecessary duplication and prevent update anomalies. A common design stores each kind of entity once and connects related tables with keys. The appropriate design depends on the application's requirements.

### 15. What is the difference between `COUNT(*)` and `COUNT(column)`?

`COUNT(*)` counts rows. `COUNT(column)` counts rows where that column is not `NULL`.

### 16. What is a view?

A view is a named query that can be queried like a table. A regular view stores the query definition, not a separate copy of its result rows.

### 17. What is the difference between `SERIAL` and identity columns?

Both can generate sequential values for new rows. Identity columns use the SQL-standard identity syntax and are generally preferred for new PostgreSQL schemas:

```sql
id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY
```

`GENERATED BY DEFAULT AS IDENTITY` also permits explicitly supplied values, subject to the column's rules.

### 18. How do you find duplicate values?

Group by the value and filter groups with more than one row:

```sql
SELECT author, COUNT(*) AS occurrences
FROM books
GROUP BY author
HAVING COUNT(*) > 1;
```

Decide how `NULL` values should be treated for the specific use case.
