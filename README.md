# Learning PostgreSQL

This folder is a hands-on workspace for learning PostgreSQL, starting with SQL fundamentals and building toward database design and Python integration.

## Learning materials

- [PostgreSQL installation and query guide](POSTGRESQL_GUIDE.md) — install PostgreSQL on Windows, connect with `psql`, create a practice database, and try common queries.
- [PostgreSQL interview questions and answers](INTERVIEW_QUESTIONS.md) — review core concepts and practice explaining them.

## Getting started

1. Follow the installation and connection steps in [POSTGRESQL_GUIDE.md](POSTGRESQL_GUIDE.md).
2. Create the `learning_db` practice database and `books` table.
3. Run the example queries, then modify them to explore the results.
4. Work through the practice prompts and add your own notes and questions to the learning materials.

## Suggested learning path

1. Query and filter data with `SELECT`, `WHERE`, `ORDER BY`, and `LIMIT`.
2. Insert, update, and delete rows safely.
3. Design tables with primary keys, foreign keys, and constraints.
4. Combine tables with joins and summarize data with grouping.
5. Learn transactions and indexes.
6. Connect PostgreSQL to a Python program.

Use only practice data while learning destructive commands such as `DELETE`, `TRUNCATE`, and `DROP`.
